# 03 組裝與接線

零件名稱對照 `STL/unit/` 的檔名。螺絲規格見 [01 零件與採購](01_零件與採購.md) 第 5 節。

## A. 擺臂與馬達

1. **樞軸軸承**：608 壓進擺臂轂的兩端，中間先放 `spacer_pivot`（Ø11.5 × 30.9 mm 墊管），讓螺絲鎖緊時夾住兩顆軸承的內圈。
2. **軸端軸承**：另一顆 608 從內側壓進外側軸承板的座孔。
3. **裝馬達**：
   - 馬達軸從「馬達座板」中間的孔穿過去，插進軸端 608。
   - 出線凸座朝樞軸方向。
   - 用 4 支 M4×10 從座板外側穿過長孔鎖進馬達。長孔涵蓋 PCD 30–46，副廠孔距不同也能鎖。
   - **馬達螺孔只有 5 mm 深，不要用更長的螺絲。**
4. **滾輪套**：TPU 滾輪套用吹風機稍微加熱，套上馬達外殼。內徑比外殼小 0.5 mm，靠過盈固定；打滑就加少量瞬間膠。
5. **走線**：馬達線沿擺臂內側用束帶固定，留足擺動餘量（擺臂會轉約 15°），從樞軸附近的孔進電控艙。

## B. 主機殼

1. **裝擺臂**：擺臂轂放進主機前段兩片耳板之間，M8×70 從外側穿過耳板與兩顆軸承，另一側鎖防鬆螺帽。墊圈只放在耳板外側。
   - 鎖到擺臂能自由擺動、沒有左右晃即可，**不要死鎖**。
2. **鎖前後段**：主機後段接上前段，4 支 M5×16 從電控艙內往後鎖，螺帽在後段接合板背面。
3. **偏心抬臂機構**：
   - 內曲柄片：M8 螺帽壓進六角槽，放到塔的內牆內側；M8×16 從內牆外側穿過來鎖進螺帽，這支螺絲就是短軸。
   - 外曲柄片：先在內側面的六角槽埋一顆 M8 螺帽，再從塔內把 Ø22 轂穿出外牆。
   - 氣壓棒上眼：放在兩片曲柄之間，兩側各一個 `spacer_eye_top`，用 M8×35 穿過兩片曲柄的銷孔，鎖防鬆螺帽。
   - 把手：套上外牆外的六角榫（六個方向只有一個能讓把手在「工作位置」時朝後水平靠在擋塊上），用 M8×16 鎖進外曲柄埋的螺帽。
4. **氣壓棒下眼**：放進擺臂上方的槽，兩側各一個 `spacer_eye_low`，用 M8×45 橫穿擺臂，鎖防鬆螺帽。
5. **電池座**：印好的 CC0 牧田座用 4 支 M5×12 鎖在主機右側牆，螺帽在牆內側。
   - 端子插 6.3 mm 公插片。
   - 正負極線從牆上的孔進主機後段，再穿過接合牆的 Ø12 孔進電控艙。

6. **緊急停止觸發桿**（主機左後方、抬臂把手下面）：
   - M4 熱壓銅螺母壓進支架的孔。
   - 觸發桿套上墊管 `spacer_kicker`，用 M4×14＋墊圈鎖進熱壓螺母。
   - 螺絲夾住的是墊管，觸發桿要能自由擺動，放開時靠在下方的休止擋上。
   - 車把拉桿與煞車線的安裝見 [05 緊急停止拉桿](05_緊急停止拉桿.md)。

## C. 接線

```
牧田 18V 電池 ── 電池座端子
   (+) ── 30 A 插片保險絲 ── XT60 ── VESC 電源 +
   (−) ───────────────────── XT60 ── VESC 電源 −

VESC 三相線 A/B/C ── 6374 三相線（順序隨意，方向用 VESC Tool 反轉）
VESC 霍爾 6 pin   ── 6374 霍爾線（5V、GND、H1、H2、H3、溫度）

VESC COMM（UART）              ESP32-C3 SuperMini
   5V  ── 16 mm 自鎖開關 ──── 5V
   GND ───────────────────── GND
   TX  ───────────────────── GPIO20（RX）
   RX  ───────────────────── GPIO21（TX）

ESP32 GPIO4 ── 12 mm 按鍵 ── GND
ESP32 GPIO3 ── 330 Ω ── 5 mm LED(+)，LED(−) ── GND
```

- 16 mm 自鎖開關切的是 ESP32 的電，等於「助力總開關」。關掉後 VESC 收不到指令，0.3 秒內停止出力。
- 真正斷電的方式是拔電池。牧田電池插著時 VESC 會持續耗電，**騎完請把電池拔下來**。
- MKS MINI V6.7 的 COMM 腳位順序請看板子上的絲印。

## D. VESC 設定（VESC Tool）

1. USB 接電腦，開 VESC Tool，更新到 FW 6.x。
2. **Motor Setup Wizard**：
   - 選 FOC、小型外轉子。
   - 電池 5S Li-ion，電流上限先填 20 A。
   - 有霍爾線就讓它偵測霍爾。
   - 偵測時把車架起來、後輪離地，**先把抬臂桿往前扳起，讓滾輪不碰輪胎**。
3. 手動調整：

| 參數（Motor Settings → General / Advanced） | 值 | 原因 |
|---|---|---|
| Motor Current Max | 35 A | 爬坡短時間用；韌體平常最多只送 28 A |
| Motor Current Max Brake | −5 A | 減少反拖打滑磨胎 |
| Battery Current Max | 20 A | 18 V × 20 A ≈ 360 W 輸入，低於檢測基準的 400 W |
| Battery Current Max Regen | −0.5 A | 不要回充牧田電池 |
| Battery Voltage Cutoff Start / End | 16.0 V / 15.0 V | 牧田 5S 過放保護（每顆 3.2 / 3.0 V） |
| Max ERPM | 16000 | Ø69 滾輪約 30 km/h，硬上限 |
| Invert Motor Direction | 依實測 | 架車測試時後輪要往前轉 |

4. **App Settings**：

| 參數 | 值 |
|---|---|
| App to Use | UART |
| UART Baudrate | 115200 |
| Timeout | 300 ms |
| Timeout Brake Current | 0 A |

## E. 韌體（ESP32-C3）

```bash
pip install platformio
```

```bash
cd firmware
```

```bash
pio run -t upload
```

燒錄後開序列埠監看（`pio device monitor`），每秒會印出段位、踏頻、車速、電壓、電流。可調參數在 `firmware/src/main.cpp` 開頭：
- 段位電流：10／18／28 A。
- 速限：22 km/h 起遞減、25 km/h 斷電。
- 停踩判定：1.2 秒。
- 低電壓降功率門檻。

**第一次配對**：
1. 打開助力總開關。
2. 轉幾圈曲柄喚醒踏頻感測器。
3. ESP32 會連上第一個廣播踏頻服務的感測器並記住它，之後只連這一個。
4. 要換感測器時，長按按鍵 6 秒清除。

**操作**：

| 按鍵 | 動作 |
|---|---|
| 短按 | 段位 0 → 1 → 2 → 3 → 0（0 = 不助力） |
| 長按 1.5 秒 | 段位歸 0 |

LED 每 2 秒閃「段位」次；快閃表示還沒連上感測器。

## F. 裝到腳踏車上

**每台車第一次（裝座管座）：**
1. 用 `tools/fit_my_bike.py` 決定座管座款式與夾具高度 s，印好三件。
2. TPU 內襯包住座管，縫朝前。
3. 前後半夾上去：
   - M5 螺帽從側邊推進後半的螺帽槽。
   - 4 支 M5×20 交叉均勻鎖到約 2–3 N·m。
   - **燕尾要朝正後方、與車子中心線對齊**，從車尾往前看燕尾要和後輪在同一直線上。
4. 魔鬼氈束帶穿過前方扣環，往上綁住座墊弓，防止整組繞座管轉。

**換車（主機）：**
1. 抬臂桿往前扳（滾輪抬起）。
2. 主機從座管座下方往上推，燕尾滑進去頂到底。
3. 從右側插入 Ø6 快拆銷，聽到喀一聲、拉不出來才算鎖好。
4. 插上牧田電池。
5. 抬臂桿往後扳到底（靠到擋塊），滾輪壓上胎頂。
6. 確認滾輪在輪胎正中央，用手轉後輪滾輪要跟著轉。

拆下就反過來：抬臂桿往前、拔快拆銷、主機往下滑出。

**換車時多一步（緊急停止）**：線管放進前段 U 型槽 → 內線從塔外牆線管座的側槽放進去、線管頭從前方推入 → 螺絲線頭放進觸發桿 → 拉一下紅色拉桿確認滾輪會抬起，再把抬臂把手扳回。細節見 [05](05_緊急停止拉桿.md)。

## G. 使用注意

- **長下坡要把抬臂桿扳起來**。車速超過約 48 km/h 時，馬達反電動勢會高過電池電壓，不受控地回灌電池並煞車。
- 雨天抓地力約剩一半（可傳推力 62–72 N），起步與爬坡要降段位。也可以換 300 N 氣壓棒。
- 輪胎會比平常磨得快（廠商與社群經驗：多 10–30%）。打滑一秒就可能磨傷胎面，所以出力是逐漸加大的（韌體每秒 25 A）。
- 胎壓不足時接觸面積變大、拖滯變大，請照胎壁標示打氣。
- 不助力時把滾輪抬起來，可以消除壓胎拖滯。估計在 20 km/h 時有 15–60 W。

## H. 保養

| 週期 | 項目 |
|---|---|
| 每次換車 | 快拆銷有沒有確實鎖住；座管座有沒有轉動或下滑 |
| 每 100 km | 座管座 M5、樞軸 M8 有沒有鬆；TPU 滾輪套磨耗與裂紋 |
| 每 500 km | 608 軸承是否順；氣壓棒有沒有漏氣（壓胎力變小，可以把抬臂桿扳到一半感受阻力） |

## I. 疑難排解

| 現象 | 檢查 |
|---|---|
| LED 一直快閃 | 踏頻感測器沒電、在「速度模式」（重裝電池切換）、或被別的裝置連走 |
| 有踩但不出力 | 車速要 > 3 km/h；段位不是 0；序列埠看 `vesc=1` 與電壓 |
| 出力時滾輪打滑尖叫 | 濕地或胎壓不足；降段位；確認滾輪在胎面中央；考慮 300 N 氣壓棒 |
| 後輪往後轉 | VESC Tool 勾 Invert Motor Direction |
| 主機晃 | 座管座螺絲、快拆銷；燕尾太鬆可在母槽貼一層 0.3 mm 膠帶 |
